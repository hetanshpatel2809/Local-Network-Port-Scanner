4. SECURITY ANALYSIS
============================================================

PORT 80 - HTTP
Potential Risk:
Unencrypted web communication may expose sensitive
information if credentials or data are transmitted.

PORT 135 - MSRPC
Potential Risk:
Unnecessary exposure of remote procedure call services
may increase the network attack surface.

PORT 139 - NETBIOS
Potential Risk:
May expose legacy network sharing and information.

PORT 445 - SMB
Potential Risk:
Weak SMB configurations or outdated versions may
expose shared files and create security weaknesses.

PORT 5432 - POSTGRESQL
Potential Risk:
Unrestricted database access may expose sensitive
information.

PORT 8000 - HTTP-ALT
Potential Risk:
The application or service running on this port
requires identification and configuration review.
